# Stash

Armazena um atualizações que ainda não foram feitos commits em um local que podemos chamar quando necessário.

# Criando um stash

Com o comando a seguir criamos um stash.

```bash
git stash
```

# Recuperando um stash

Para recuperar um stash o comando a seguir precisa ser executado.

```bash
git stash apply
```

# Listando stash

Para listar stash o comando a seguir precisa ser executado.

```bash
git stash list
```

# Limpando stash

Para limpar a lista de stash o comando a seguir precisa ser executado.

```bash
git stash clear
```
