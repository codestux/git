# Git

É o sistema para rastrear e monitorar mudanças em arquivos que estejam sendo usados individualmente ou em grupo, ous eja, um controle de versões que permite que uma ou mais pessoas tenham controle de alterações realizadas em arquivos.

Ele não guarda as diferenças entre os arquivos, mas o estados de cada arquivo.

Podemos sempre ter acesso aos estados anteriores dos arquivos que estão sendo geridos pelo Git nos seus repositórios.

Ele pode ser utilizado em um servidor remoto para centralizar o controle de versões em uma equipe.

## Algumas funcionalidades

1. Pode reverter alterações nos arquivos
2. Colaboração
3. Auditoria e rastreamento de alterações
4. Ramificação e mesclagem

## Tipos de Controle de Versão

### Centralizado

Permite compartilhar arquivos e ter acesso as versões mais recentes. Precisa de conexão contante com o servidor onde está o repositório.

### Distribuído

Permite compartilhar arquivos e ter acesso a todo o histórico de mudanças deste o início do projeto e não precisa está conectado ao servidor do repositório constantemente, somente para alguns comandos.

O Git é um Controle de Versão do tipo distribuído.

## O que é um repositório

É um local que armazena e gerencia todo o histórico de mudanças que ocorrem nos arquivos/pastas que estão neste local.

Pode ser local ou remoto e pode ser público ou privado.

## Github

Repositório remoto do Git que permite que várias pessoas possam compartilhar projetos. É possível fazer downloads, clonar, merge, etc.
