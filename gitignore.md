# Git Ignore

No Git podemos criar um arquivo **.gitignore** com os nomes de arquivos ou pastas que o Git não deve monitorar suas versões ou enviar para repositórios públicos.

Um diretório/pasta não pode ser monitada pelo Git. Mas, adicionando um arquivos neste pasta/diretório e, os arquivos não inseridos no arquivo **.gitignore**, o Git passa a monitorar.

O conteúdo do arquivos .gitignore pode ter o modelo abaixo.

```vim
file.json
*.json
```

## Modelos de .gitignore

Existem diversos modelos prontos de arquivo .gitignore para diversos projetos e linguagens que podem ser usados nos nosso projetos e realizar as adaptações necessárias.

[Repositório dos modelos](https://github.com/github/gitignore)
